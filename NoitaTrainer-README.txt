Noita 即时修改器 4.9
====================

适用环境
--------
- Windows 10/11 x64
- Noita Steam 正式版
- 本构建针对本机 Noita build：9dbd52ced019a643169a2db02f46c77f8766c6e5

安装与升级
----------
1. 运行 NoitaTrainer.exe。它是自带 .NET 8 运行时的单文件程序，无需另装运行库。
2. 确认顶部检测到正确的 Noita 游戏目录，然后点击“安装/修复配套模组”。
3. 在 Noita 的 Mods 菜单中允许 Unsafe mods，并启用“Codex Noita Trainer Bridge”。
4. 首次安装或从任何旧版本升级到 4.9 时，必须点击一次“安装/修复配套模组”，以更新桥接协议与新增功能。
5. 重新启动或重新载入 Noita，进入一局游戏。顶部显示绿色“已连接”后即可使用。
6. 重复启动 NoitaTrainer.exe 时不会打开第二个窗口，而是把已运行的窗口弹出到前台；关闭窗口后才会真正退出程序。

信息显示
--------
- 实时显示玩家与镜头坐标、当前种子、本局游戏时间、杀敌数、承受伤害、累计恢复生命、射击次数和累计获得的总黄金。
- 额外显示探索地点数、拾取物品数、拾取魔杖数、拾取额外生命数和踢击次数；其中探索地点数等来自原版当前局统计，“拾取物品数”与“拾取魔杖数”由修改器自行统计（见下）。所有实时统计每行显示两项。不重复显示游戏 HUD 已有的当前黄金，也不加入原版记录不可靠的传送次数。
- “拾取魔杖数”与“拾取物品数”按实体逐帧统计：每根魔杖或物品第一次进入法杖栏或物品栏时 +1，同一件被换出再换回、更换法术等都不重复计数，长相相同但不同的另一件会正常计数。开局自带的起始魔杖、炸弹魔杖与起始药水不计数。配套模组自游戏启动即运行，因此中途打开修改器也会保留本局已有的计数；继续旧存档时，存档中已有的物品与魔杖不计入（引擎不保留拾取历史）。
- 上述实时数值均可用鼠标拖选，并可通过右键菜单或 Ctrl+C 复制；空间传送页的玩家实时坐标同样支持复制。
- “总黄金”使用原版 gold_all 统计，花费黄金不会令其减少。
- “恢复生命数”由桥接逐帧累计玩家实际生命上升量并乘以 25，包含治疗液等不一定进入原版 healed 统计的恢复来源；数据随当前存档保存，新开世界后从零开始。
- “修改种子”可把 1 至 4294967295 的整数预设给下一次普通新游戏；桥接只有在确认刚生成的新世界实际采用该种子后才会自动清除预设，也可提前点击“取消预设”。继续旧存档或进入每日挑战不会消费该预设。
- “显示怪物血量”会在镜头内怪物头顶显示按 HUD 比例换算的实际剩余生命。
- “显示玩家坐标”会在游戏画面顶部中央显示玩家当前位置。
- 游戏内数字使用圣山商品价格采用的原版像素字体。

空间传送
--------
- 可输入任意 X、Y 坐标并传送，也可使用 79 个分类排列的地点按钮。
- 地点分为常规地形与隐藏区域、Boss、重要物品与任务设施、精粹相关及魔球室。
- 点击地点按钮会同步填写坐标，并在传送后清除玩家惯性。
- “血肉地狱（西侧）”坐标为 (6044, 7179)。
- “允许游戏后台运行”会关闭 Noita 的失焦暂停。游戏运行中更改时，会在退出后再次写入并从下次启动生效。

一键操作
--------
- 页面仅显示功能控件；把鼠标悬停在勾选框或按钮上片刻即可查看详细说明。
- 自动收集金块：勾选后立即把所有已加载的普通金块和血金移动到玩家处，并持续处理后来生成或加载的金块。勾选状态保存在修改器设置中，新开一局或重启修改器后仍会自动同步，直到手动取消。
- 幽灵透视：持续启用原版 `magic_eye` 显形组件，使原本需要手持邪王真眼才能看见的幽灵类生物自动显形；不会生成邪王真眼、激光或隐藏平台。勾选状态同样会被记住。
- 回满血量：把当前生命恢复到现有最大生命。
- 刷新法术：使用 Noita 原生法术次数恢复流程，处理玩家法术栏和四根随身法杖中的限次法术；通常不受“无限法术”影响的法术也会恢复到自身最大次数。
- 黄金世界：使用原版全世界转换机制，将当前和以后加载的材质转换为普通黄金。
- 毒金世界：使用原版全世界转换机制，将当前和以后加载的材质转换为毒金。
- 和平：把本局全局阵营关系修正为友好，使当前和以后生成的生物不再敌对。
- 和平+无敌：在和平基础上，为本局玩家添加永久的全伤害防护和变形免疫，并持续防止致死；不会改变画面上可见的最大生命。
- 消灭所有生物：只对当前已加载、除玩家外且同时具有生命、阵营与 AI/生物控制组件的生物施加正常致死伤害，包括敌对、中立、友好生物和 Boss；不会处理 TNT、爆炸水晶、管道、巢穴、假人、投射物或机关。
- 消灭所有敌对生物：只对当前已加载、带有 enemy 标签且同时具有阵营与 AI/生物控制组件的生物施加正常致死伤害。
- 魅惑所有生物：只永久魅惑当前已加载且具有 AI/生物控制组件的真正生物，同时把其阵营同步为玩家阵营，避免只显示爱心却仍继续攻击玩家；不会处理 TNT、假人、投射物或其他可破坏物体。个别具有特殊脚本的 Boss 仍可能不完全服从普通 AI 阵营规则。
- 消灭所有实体：沿用 3.6 及更早版本“消灭所有生物”的宽泛范围，对所有已加载、带有 mortal 标签且具有生命组件的非玩家实体施加正常致死伤害，因此会引爆 TNT、爆炸物或触发相关机关。
- 爆尸所有生物 / 爆尸所有敌对生物：先给相应已加载生物附加原版“爆炸尸体”效果，再施加正常致死伤害；爆炸会伤害其他实体、破坏地形并可能连锁，同时临时给予玩家原版爆炸免疫。
- 引爆所有金块：按照原版“爆炸金块”天赋的价值缩放参数引爆所有已加载普通金块和血金；爆炸不会伤害玩家，金块直接消失且不会被获得。
- 4*更多友爱 / 4*更多仇恨：在当前全局阵营关系修正上增加或减少 100，等效于四层原版天赋关系效果；不添加天赋图标或永久进度。
- 自杀：弹出二次确认后，对玩家施加正常致死伤害并进入原版死亡/游戏结束流程。

添加天赋
--------
- 位于“一键操作”右侧，按游戏“进展”栏从左到右、从上到下的顺序排列天赋。
- 顶部搜索框会按照中文名、英文名或内部 ID 实时筛选，支持完整名称和部分名称匹配；清空搜索后恢复进展顺序。
- 每个天赋均为独立的自绘图标按钮，并以三列网格排列；按钮使用 10.5pt 字体和 36×36 图标，缩小窗口时仍会完整显示并保持垂直居中。
- 中文名称与简短描述来自 Noita Wiki 中文站当前使用的“伟大汉化”数据；把鼠标悬停在按钮上即可查看描述。
- “生成在玩家脚下”与“直接获得该天赋”是严格二选一的操作方式。
- 数量支持 1 至 100；点击天赋按钮后按当前操作方式和数量执行。
- 可叠加天赋可以重复获得，某些特殊天赋具有不可逆的本局效果。

添加状态
--------
- 位于“添加天赋”右侧，收录 59 种状态：52 种通过原版效果系统施加，另有 7 档饱食度状态（最底限满足、满足、完全饱足、吃撑了、胀爆了、腹中满溢、又撑又胀），参考 Noita Wiki 中文状态页整理，涵盖沾染、摄取、魔药增益、变形、法师减益与削弱诅咒等类别（含狂暴、变形、冻结等负面或恶搞状态）。
- 页面沿用三列图标按钮、实时搜索、结果计数和悬停说明；图标取自游戏原版状态指示贴图，已打包进 EXE，程序运行时不需要联网。
- “临时效果”与“永久效果”是严格二选一的持续方式；临时效果时长支持 1 至 3600 秒，默认 30 秒。
- 点击状态按钮即通过原版 `LoadGameEffectEntityTo` 对当前玩家施加对应状态；施加的状态会在游戏内右侧状态栏显示图标与说明（少数原版即无图标的设计除外）。雨云、雷云、酸雨诅咒在原版中本身即为永久设计，选择临时时长也无法令其自动消失。
- 页面顶部“清除全部状态”在二次确认后，移除玩家身上的状态效果（含通过本页施加的永久状态），并用水清洗沾染类状态；天赋与饱食度不受影响。
- 饱食度条目会直接写入原版饱食度数值，状态随消化自然下降；超过 100% 后按原版机制持续损失生命；“又撑又胀”在二次确认后立即造成当前生命值两倍的伤害。
- 专属重力领域、晕眩等少数机制特殊的状态不在收录范围内。

添加法术
--------
- 位于“添加状态”右侧，按游戏“进展”栏从左到右、从上到下的顺序排列法术。
- 顶部搜索框会按照中文名、英文名或内部 ID 实时筛选，支持完整名称和部分名称匹配；清空搜索后恢复进展顺序。
- 每个法术均为独立的自绘图标按钮，并以三列网格排列；按钮使用 10.5pt 字体和 36×36 图标，缩小窗口时仍会完整显示并保持垂直居中。
- 中文名称与简短描述来自 Noita Wiki 中文站当前使用的“伟大汉化”数据；把鼠标悬停在按钮上即可查看描述。
- “生成在玩家脚下”与“直接获得该法术”是严格二选一的操作方式，数量支持 1 至 100。
- 直接获得会调用原版物品拾取接口，将创建的法术送入玩家法术栏。
- 法术栏已满时，“直接获得该法术”会提示“法术槽已满”并撤销多余的法术卡片，不会把卡片塞进普通物品栏。

添加事件
--------
- 位于“添加法术”右侧，按当前版本原版 `streaming_events` 目录顺序列出 96 个 Twitch Integration 事件。
- 页面沿用三列按钮、实时搜索、结果计数和悬停说明，不显示图标，也没有操作方式或数量选项。
- 中文名称和简短说明采用当前游戏 `common.csv` 自带的简体中文译文；搜索支持中文名、英文名和内部 ID。
- 点击事件按钮会通过原版 `_streaming_run_event` 流程立即触发事件；包含倒计时的事件仍按原版延迟机制执行。

添加药水
--------
- 位于“添加事件”右侧，可搜索并组合当前 Noita Wiki 材料表中的 465 种材质。
- 材质严格分为六类并依次显示：火花、液体、粉末/砂、固体、气体、Box2D；不再把粉末和 Box2D 混入固体。
- 中文名、英文名、内部 ID、分类及排列顺序均与 Noita Wiki 中文材料页逐项核对；Wiki 尚未翻译的 `cloth_box2d` 已补为“布料”。
- 每种材质均使用 Noita Wiki 的 `Material_<内部 ID>.png` 原图预览；图片已打包进 EXE，程序运行时不需要联网。
- 烧瓶使用原版空烧瓶 `potion_empty.xml`，容量为 1000；袋子使用配套模组提供的无随机填充空袋，容量为 1500。
- 配方中每项“数量（%）”都是相对于所选容器总容量的绝对百分比。例如烧瓶 50% 为 500 单位，袋子 50% 为 750 单位。
- 顶部“数量（%）”是允许装入的总量上限。配方合计可以小于该上限并留下空余容量，但超过上限时会弹出警告并禁止生成。
- 空烧瓶和空袋都启用原版材质反应；例如 50% 冰水与 50% 水会继续按原版反应规则逐渐冻结。

添加物品
--------
- 位于“添加药水”右侧，收录 64 种物品：闪耀魔球、坏掉的魔杖、邪王真眼、月亮、各种石头、蛋、精髓、罐子、骰子，以及翠玉石板等全部书籍；不含魔药与粉末口袋（添加药水页已覆盖）。
- 页面沿用三列按钮、实时搜索、结果计数和悬停说明，图标取自游戏原版贴图；操作方式与“添加法术”一致：可“生成在玩家脚下”或“直接获得该物品”。
- 直接获得会调用原版物品拾取接口；部分物品（如法术刷新器、蛋）拾取后会立即生效，不会进入物品栏。

魔杖管理
--------
- 位于“添加物品”右侧；初始只显示“读取当前魔杖栏”按钮。
- 读取后按照物品栏格位顺序，一次列出当前魔杖栏中的 0 至 4 根魔杖，以及乱序、单次施放数、施放延迟、充能时间、法力上限、法力恢复速度、容量、散射和速度加成。
- 施放延迟与充能时间由原版内部帧数除以 60，并按照游戏界面的两位小数形式显示；修改时会换算回最接近的整帧数。
- 速度加成直接读取和写入原版 `gunaction_config.speed_multiplier`；该字段可修改，原版程序生成法杖时也使用同一字段。
- 在表格中选中任意魔杖后，可以编辑全部上述属性并点击“修改”即时生效。如果魔杖已被丢弃、换位或移出魔杖栏，修改器会拒绝旧实体并要求重新读取。
- 下方始终释放法术区沿用“添加法术”页的三列图标按钮、搜索和悬停描述；点击法术会使用原版永久附着流程加入所选魔杖，并自动增加一个容量槽。允许添加多个或重复的始终释放法术。

角色管理
--------
- 位于“魔杖管理”右侧；初始只显示“读取当前角色信息”按钮。
- 读取后会列出并允许修改 13 项属性：金钱、当前血量、最大血量、肺活量上限、当前肺活量、最大浮空能量、当前浮空能量、空中浮空恢复速度、地面浮空恢复速度、奔跑速度、水平飞行速度、跳跃速度和重力。
- 金钱使用原版 `WalletComponent.money` 整数值；血量会把原版内部值乘以 25，显示和填写的都是游戏界面采用的实际血量。
- 肺活量分别使用原版 `air_in_lungs_max` 和 `air_in_lungs`；浮空能量使用 `CharacterDataComponent` 的四个原生字段；移动、跳跃与重力使用 `CharacterPlatformingComponent`。跳跃速度保留原始方向符号，向上通常为负数。

结局模拟说明
------------
- “黄金世界”“毒金世界”“和平”“和平+无敌”只模拟对应的局内效果。
- 它们不会调用正式结局函数，不会重建世界，不会授予项链/红宝石，也不会写入对应结局、成就或永久进度。
- 世界材质转换与和平效果在当前一局内不可由修改器撤销；使用前建议备份重要长周目。
- “消灭”与“魅惑”按钮不是持续效果，只处理点击时已经加载的实体；后来生成的生物不受影响。

实现与安全说明
--------------
- 程序不会注入 DLL，不扫描或修改 Noita 进程内存，也不联网。
- EXE 只向配套模组目录写入命令文本；实际效果由 Noita 自带的 Lua 实体 API 完成。
- 配套模组请求不受限 Lua API，只用于读写自身 bridge 目录中的 command.txt、status.txt、wands.txt、character.txt 和一次性 next_seed.txt；安装时还会写入自身 entities 目录中的空袋模板。
- 使用模组会令本局被标记为 Modded，原版成就或进度统计可能不会更新。
- 建议在操作重要长周目前备份存档。

常见问题
--------
- 显示“未连接”：确认配套模组已启用、Unsafe mods 已允许，并且已经进入一局游戏。
- 显示“配套模组需更新”：点击“安装/修复配套模组”，然后重新启动或重新载入 Noita。
- 自动收集金块或幽灵透视勾选后暂时没有反应：确认顶部为绿色“已连接”；桥接在新一局初始化后会自动再次同步勾选状态。
- 部分 Boss 没有被魅惑：这是其自身 AI 或免疫逻辑造成的，修改器仍会为其加载永久魅惑效果。
- Windows SmartScreen 提示：此 EXE 是本地构建且没有商业代码签名证书；可先阅读随附源代码再决定是否运行。

卸载
----
1. 在 Noita 的 Mods 菜单中停用 Codex Noita Trainer Bridge。
2. 退出游戏后，删除 Noita\mods\codex_noita_trainer_bridge 文件夹。
